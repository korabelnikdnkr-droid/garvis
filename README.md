# 🤖 Голосовой ассистент «Джарвис» (Jarvis) для Windows 11

Высокопроизводительный, модульный, событийно-ориентированный голосовой ассистент нового поколения для Windows 11. Построен на стыке передовых нативных технологий: **Rust (Tokio)**, **Tauri v2**, оффлайн-распознавания **Vosk**, языкового интеллекта **xAI Grok** и гибридного синтеза речи **Edge-TTS / Windows SAPI**.

---

## 🏛️ Архитектура системы

- **OS Target:** Windows 11 (нативные Win32, COM, WMI, CoreAudio API).
- **Backend:** Rust 2021 + многопоточный асинхронный рантайм `tokio`.
- **Frontend:** Tauri v2 + React 19 + TailwindCSS + Motion (Framer Motion).
- **Audio Pipeline (STT):** 100% локальный оффлайн-захват микрофона (`cpal`) с ресемплингом 16 кГц Mono PCM и непрерывным сканированием кодового слова **«Джарвис»** через `Vosk`.
- **The Brain (LLM):** xAI Grok API (`grok-beta`) с поддержкой **Function Calling (Tools)** и потоковой передачей токенов (Streaming SSE).
- **Voice Output (TTS):** Гибридный синтез:
  - *Основной:* Облачный Microsoft Edge-TTS (`ru-RU-DmitryNeural`).
  - *Резервный:* Мгновенный оффлайн-фоллбэк на нативный **Windows SAPI** (`System.Speech`), если интернет недоступен.
- **Barge-in Logic:** Джарвис мгновенно замолкает, если пользователь начинает говорить во время ответа ассистента.
- **Хранилище секретов:** Windows Credential Manager (`keyring`) — ключ API никогда не хранится в открытом виде на диске.

## 🚀 Быстрый старт

### 1. Загрузка модели распознавания речи Vosk (Russian)

Для оффлайн-детекции кодового слова «Джарвис» и распознавания речи требуется компактная русская модель Vosk:

1. Скачайте официальный архив модели:  
   👉 [vosk-model-small-ru-0.22.zip](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip) (размер всего ~45 МБ).
2. Распакуйте архив в корень проекта в папку `models/` так, чтобы получился путь:
   ```text
   jarvis-assistant/models/vosk-model-small-ru/
   ├── am/
   ├── conf/
   ├── graph/
   └── ivector/
   ```

### 2. Установка зависимостей интерфейса

Убедитесь, что установлены **Node.js (>= 20)** и **Rust (>= 1.78)**:

```bash
# Установка NPM зависимостей
npm install
```

### 3. Запуск в режиме разработки

Для запуска интерактивного окна ассистента с горячей перезагрузкой и системным треем:

```bash
# Запуск через Tauri CLI
npm run tauri dev
# или напрямую через Cargo:
cargo tauri dev
```

## 🔑 Настройка ключа xAI Grok API

1. Запустите приложение.
2. В верхнем правом углу окна нажмите на иконку ⚙️ (**Настройки**).
3. Введите ваш ключ API xAI (формата `xai-...`).
4. Нажмите кнопку **«Проверить»** — ассистент выполнит легковесный асинхронный Ping-запрос к `api.x.ai` и подтвердит валидность ключа.
5. Нажмите **«Сохранить»** — ключ будет надежно записан в системный **Windows Credential Manager**. Ключ никогда не передается открытым текстом.

## 🛠️ Поддерживаемые команды и инструменты Windows 11

Джарвис автономно определяет, когда требуется поддержать разговор, а когда — выполнить нативное действие в системе:

| Инструмент | Пример голосовой команды | Системное действие |
| :--- | :--- | :--- |
| **Звук** | «Джарвис, сделай громкость на 80%» | Регулировка уровня аудиомикшера Windows |
| **Яркость** | «Джарвис, поставь яркость экрана на максимум» | Управление подсветкой дисплея через WMI |
| **Программы** | «Джарвис, запусти калькулятор / блокнот» | Нативный запуск `calc.exe`, `notepad.exe`, `wt.exe` |
| **Проводник** | «Джарвис, открой папку Загрузки» | Открытие папки пользователя в проводнике Windows |
| **Поиск** | «Джарвис, найди в интернете последние новости» | Запуск браузера по умолчанию с поисковым запросом |
| **Зрение** | «Джарвис, сделай снимок экрана» | Захват кадра дисплея через библиотеку `screenshots` |
| **Таймер** | «Джарвис, поставь таймер на 5 минут на кофе» | Фоновый асинхронный таймер с будильником |
| **Умный дом** | «Джарвис, выключи свет в гостиной» | Вызов структурного хука IoT / Home Assistant |

## 📦 Сборка автономного релиза (.exe / .msi)

Для создания оптимизированного установщика Windows 11:

```bash
# Сборка готового инсталлятора
cargo tauri build
```

Готовые файлы сборки будут созданы в каталоге:
- `.exe` (NSIS Installer): `src-tauri/target/release/bundle/nsis/Jarvis_1.0.0_x64-setup.exe`
- `.msi` (Windows Installer): `src-tauri/target/release/bundle/msi/Jarvis_1.0.0_x64_ru-RU.msi`

Особенности сборки:
- Включена максимальная оптимизация (`opt-level = 3`, `lto = true`, `strip = true`).
- Отключено окно отладочной консоли (`windows_subsystem = "windows"`).
- Сворачивание в системный трей при клике на крестик или кнопку минимизации.

## 🛡️ Безопасность и надежность

- **Zero Unwraps:** Все операции сетевого ввода-вывода, COM-интерфейсов и аудиопотоков обернуты в строгий тип `JarvisResult<T>`.
- **Non-blocking UI:** Ни одна операция (Vosk FFI, Grok API, системные утилиты PowerShell) не блокирует главный графический поток приложения.
- **Graceful Shutdown:** При закрытии приложения все дескрипторы микрофона и потоков аудио корректно закрываются без утечек ресурсов и зависших фоновых процессов.
